Conectar ao Google Sheets

Cole a URL /exec do Apps Script e o API_TOKEN. A planilha pode (e deve) ficar privada — o que precisa ser público é só o App da Web do script.

  1. Apps Script → Implantar → Gerenciar → ✏️
  2. Executar como: Eu
  3. Quem tem acesso: Qualquer pessoa (anônimo — não “com Conta Google”)
  4. Nova versão → Implantar → copiar URL /exec

Teste: na aba anônima, a URL com ?action=getAll&token=SEU_TOKEN&callback=cb deve mostrar cb({...}), não login do Google.

Abra o Monitor pelo Apps Script

O GitHub Pages não consegue conectar à sua planilha enquanto o script pedir login do Google (erro Failed to fetch).

No celular / PC: entre na sua conta Google e abra a URL do app que termina em /exec (a mesma da implantação do Apps Script). Favorite essa URL.

Não cole URL/token aqui. Depois de atualizar os arquivos HTML no Apps Script e fazer Nova versão da implantação, a tela do Monitor aparece ao abrir o /exec.

Avançado: forçar conexão via Pages (só se acesso for “Qualquer pessoa” anônimo)

# Deploy checklist — GitHub Pages

1. Push deste repositório para o GitHub (`main`).
2. Settings → Pages → Branch `main` / folder `/docs`.
3. Confirme que `docs/index.html` abre na URL do Pages.
4. Configure Apps Script (`gas/Code.gs`) e cole URL + token no site.

Arquivo `.nojekyll` nesta pasta garante que o GitHub não processe Jekyll.
